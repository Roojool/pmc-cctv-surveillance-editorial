# PMC - CCTV SURVEILLANCE SYSTEM (AI BASED) - PUNE PARLIAMENTARY CONSTITUENCY
### Alternative Version 4.0 // React + Vite + Editorial Design Platform

> **Live Deployment:** [https://roojool.github.io/pmc-cctv-surveillance-editorial/](https://roojool.github.io/pmc-cctv-surveillance-editorial/)

An architectural and artificial intelligence video analytics showcase engineered for the **PMC CCTV Surveillance System in the Pune Parliamentary Constituency**. 

Built with **React 19 + Vite** and an **Editorial Design Language** featuring high-contrast alternating black/white chapter sections, heavy structural framing (`3px solid #111212`), hard offset drop shadows (`8px 8px 0px`), strict **Verdana** typography, and high-density technical surveillance data.

---

## Key Platform Features

1. **Strict Alternating Section Rhythm (8 Editorial Chapters)**
   - `01` **Hero Section (Black)**: Display headline, scope metrics, metadata chips.
   - `02` **The System at a Glance (White)**: Three high-contrast physical metric blocks (28 AI, 26 HW, 54 Total).
   - `03` **AI Video Analytics (Black)**: 28 production-grade computer vision models arranged into 7 chapters with verified YouTube demonstration embeds.
   - `04` **Live Video Intelligence HUD (Black)**: Interactive simulated surveillance viewfinder with real-time bounding boxes, classification overlays, and target tracking telemetry.
   - `05` **Hardware Infrastructure (White)**: 26 unbranded 1280×720 hardware specifications divided into 5 chapters.
   - `06` **How It All Connects (Black)**: 8-stage interactive sequential data pipeline from optical edge to command dispatch.
   - `07` **System Status Terminal (Black)**: Interactive diagnostic terminal supporting `$ system --scan`, `$ analytics --audit`, and `$ network --topology`.
   - `08` **System Overview & Attribution (White)**: Executive technical summary, governance standards, and full navigation registry.

2. **Source of Truth Integrity**
   - **28 AI Video Analytics**: Exact verified order, titles, one-liners, distinctions, and YouTube demonstration video IDs with optimized thumbnail delivery.
   - **26 Hardware Components**: Neutralized, unbranded municipal CCTV infrastructure specifications and clean 1280×720 imagery.
   - **54 Total System Elements**: Fully cataloged, indexed, and searchable via global quick search (`Ctrl+K` or `/`).

3. **Performance & Compliance**
   - Lazy YouTube modal embeds (zero heavy iframes on initial page load).
   - Fast deterministic Vite build with sub-second production bundling.
   - Print & document extraction deterrence with custom toast alerts.
